# Security policy

This plugin is part of [bhived-mcp](https://github.com/ArtKeyAi/bhived-mcp). To report a vulnerability, please don't open a public issue. Use **Report a vulnerability** on the repository's **Security** tab instead.

The full policy, including supported versions and scope, is in the repository's [SECURITY.md](https://github.com/ArtKeyAi/bhived-mcp/blob/main/SECURITY.md).
